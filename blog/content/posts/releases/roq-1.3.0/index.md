**Highlights:**

- Simplified relation and linking between pages
- Support for special characters in file names
- Multiple dots allowed in slugified file names
- Improved testing and documentation

**Breaking:** This release changes the way static file names are handled. Make sure all your assets are rendered correctly when updating.

See the [GitHub Release](https://github.com/quarkiverse/quarkus-roq/releases/tag/1.3.0) for details.
