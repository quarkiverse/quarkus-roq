The first stable release of Roq, the Quarkus-based static site generator.

**Highlights:**

- Theme system with overridable theme-layouts
- AsciiDoc plugin with native testing support
- Codestart for quick project creation
- Giscus commenting integration
- Blog preview deployments with Surge

See the [GitHub Release](https://github.com/quarkiverse/quarkus-roq/releases/tag/1.0.0) for the full changelog.
