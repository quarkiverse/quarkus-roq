[.description]
--
Where to read the last modification date of pages and documents from (used for `<lastmod>`), when not set in the FM data with `last-modified-at`.

In dev mode, it defaults to `fs` to keep startup fast on large sites; set `%dev.quarkus.roq.sitemap.last-modified=git` to override it.
