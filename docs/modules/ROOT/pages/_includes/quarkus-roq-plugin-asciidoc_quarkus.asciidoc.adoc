[.description]
--
Controls whether all AsciiDoc templates should be parsed by Qute.

When set to `true`, Qute will parse AsciiDoc files. Files with the `:qute:` attribute in their header will override this config.

By default, Qute parsing is disabled for AsciiDoc templates.

[.description]
--
The AsciiDoc attributes applied when a page is rendered, and when a page is converted to Markdown at build time (the Markdown twin plugin). The same properties configure the AsciidoctorJ plugin, see its `attributes`.

For a boolean attribute (a flag that is set or unset, such as `sectanchors`), use the value `"true"`, which is converted to an empty value before it reaches the parser.
